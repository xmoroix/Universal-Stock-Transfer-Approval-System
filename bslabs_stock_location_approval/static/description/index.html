Stock Location Approval

Universal approval workflow for stock transfers from restricted locations

✨ Key Features

✓ Mark any stock location as requiring approval for outgoing transfers
✓ Assign multiple responsible users who can approve transfers
✓ Automatic notifications via activities, email, and chatter
✓ Block transfer validation until approval is granted
✓ Clean UI with smart button status indicators
✓ Color-coded approval status in list view
✓ Complete audit trail with approval history
✓ Bilingual support (English & French)
✓ Works seamlessly with standard Odoo stock workflows

🎯 Perfect For

🏥 Healthcare - Pharmacy Control

Prevent medication dispensing without pharmacist approval. Ensure all drugs leaving the pharmacy are authorized by qualified personnel.

💎 High-Value Inventory

Require management approval before expensive items or precious materials leave secure storage areas.

🏭 Manufacturing - Quality Control

Implement quality checkpoints requiring QC inspector approval before products can be shipped to customers.

🏢 Multi-Warehouse Management

Control internal transfers between warehouse sections with supervisor authorization requirements.

🔬 Laboratory - Controlled Substances

Track and authorize all removals from controlled substance storage with proper documentation.

⚙️ Simple Configuration

Step 1: Configure Locations

Navigate to Inventory → Configuration → Locations and:

1 Check "Require Approval for Outgoing"
2 Select "Responsible Users" who can approve
3 Save - that's it!
✓ That's all! The approval workflow is now active for that location. Any transfer FROM this location will automatically require approval.

🔔 Automatic Notifications

When a transfer requires approval, responsible users are notified via:

📊
Activity Dashboard New activity appears with transfer details
✉️
Email Alerts Automatic email notification (if email configured)
💬
Chatter Messages @mention in the transfer's chatter

Approvers can quickly find their pending approvals using the "My Approvals" filter.
